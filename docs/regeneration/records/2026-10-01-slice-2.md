- **Gate:** `sdk/test/contract.test.ts` →

  `tokens == ["token1","token2"]` and `result.answer == "token1token2"`.
  Bounded by a 2s test timeout. Assertion identity for the recipe:
  `contract.test.ts / onContent fires before the source stream closes`.
- **Reference (incremental impl):** SDK suite 25 tests, **25 pass**, 0
  fail/skip, exit 0 — remains green.
